[story]
Bitty: "Two pointers, one at each end, walking towards the middle."
Write reverse_array() using pointers only.

[talk]
@walk EAST 1
Reverse the array again, but with no `[ ]`. Use two pointers: `left` at the start, `right` at the end.
Swap what they point at, then move `left` forward and `right` back.
Keep going while `left < right`. When they meet in the middle, you're done!

[lesson]
Two pointers, one from each end:

    int *left  = arr;
    int *right = arr + size - 1;

    while (left < right) {
        int temp = *left;
        *left = *right;
        *right = temp;
        left++;
        right--;
    }

arr + size - 1 is the address of the
LAST box.

Exam 2: reverse_array.

[hint]
left and right are already set up. Swap the values they point at.
While left < right: swap *left and *right, then left++ and right--.
int *left = arr; int *right = arr + size - 1; swap *left and *right while left < right.

[solution]
void reverse_array(int *arr, int size) {
    int *left = arr;
    int *right = arr + size - 1;
    while (left < right) {
        int temp = *left;
        *left = *right;
        *right = temp;
        left++;
        right--;
    }
}

[tests]
reverse_array({1, 2, 3, 4, 5}, 5) then #1 == {5, 4, 3, 2, 1}
reverse_array({7, 8}, 2) then #1 == {8, 7}
reverse_array({42}, 1) then #1 == {42}
reverse_array({1, 2, 3, 4}, 4) then #1 == {4, 3, 2, 1}

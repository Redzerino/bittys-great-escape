title: 4.1  Counted Loops
type: repair

[story]
Bitty: "The core needs powers. 2 to the power of 3 is 2 times 2 times 2."
Write power() using a for loop.

[talk]
@walk EAST 1
The Processing Core does the heavy lifting, and that means loops.
`power(2, 3)` means 2 times itself 3 times: 2 * 2 * 2 = 8.
Start a `result` at 1, then use a `for` loop to multiply it by `base`, `exp` times.
Why start at 1 and not 0? Because 0 times anything is 0! And anything to the power of 0 is 1, which this handles for free.
Watch `i` and `result` change together in the Inspector.

[lesson]
A for loop runs a set number of times:

    for (int i = 0; i < exp; i++) {
        result = result * base;
    }

power(2, 3):
    start   result = 1
    i = 0   result = 2
    i = 1   result = 4
    i = 2   result = 8   loop ends

If exp is 0, the loop never runs and
result stays 1. Correct!

[hint]
int result = 1; for (int i = 0; i < exp; i++) result = result * base; return result;

[code]
// STAGE 4.1: COUNTED LOOPS
// power(2, 3) -> 8   (2 * 2 * 2)
// power(5, 0) -> 1

int power(int base, int exp) {
    int result = 0;

    return result;
}

[solution]
int power(int base, int exp) {
    int result = 1;
    for (int i = 0; i < exp; i++) {
        result = result * base;
    }
    return result;
}

[tests]
power(2, 3) == 8
power(5, 0) == 1
power(3, 4) == 81
power(10, 2) == 100
power(7, 1) == 7

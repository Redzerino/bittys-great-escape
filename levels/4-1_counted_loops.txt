title: 4.1  Counted Loops
type: repair
buttons: 0 | 1 | exp | base

[story]
Bitty: "The core needs powers. 2 to the power of 3 is 2 times 2 times 2."
Write power() using a for loop.

[talk]
@walk EAST 1
`power(2, 3)` means 2 * 2 * 2 = 8: multiply by `base`, `exp` times.
Start `result` at 1, not 0. 0 times anything is 0!
Fill the gaps, and watch `i` and `result` change together.

[lesson]
A for loop runs a set number of times:

    for (int i = 0; i < exp; i++) {
        result = result * base;
    }

power(2, 3):
    start   result = 1
    i = 0   result = 2
    i = 1   result = 4
    i = 2   result = 8   loop ends

If exp is 0, the loop never runs and
result stays 1. Correct!

[hint]
Start result at 1, then multiply it by base, exp times.
Use for (int i = 0; i < exp; i++) and inside it result = result * base;
int result = 1; for (int i = 0; i < exp; i++) result = result * base; return result;

[code]
// STAGE 4.1: COUNTED LOOPS
// power(2, 3) -> 8   (2 * 2 * 2)
// power(5, 0) -> 1
// Fill in the gold gaps!

int power(int base, int exp) {
    int result = ___;
    for (int i = 0; i < ___; i++) {
        result = result * ___;
    }
    return result;
}

[solution]
int power(int base, int exp) {
    int result = 1;
    for (int i = 0; i < exp; i++) {
        result = result * base;
    }
    return result;
}

[tests]
power(2, 3) == 8
power(5, 0) == 1
power(3, 4) == 81
power(10, 2) == 100
power(7, 1) == 7

[story]
Bitty: "Copy the escape plan into the transfer buffer. Pointers only, and don't forget the end."
Write copy_string() without [ ].

[talk]
@walk EAST 1
Copy one string into another, pointers only.
`*dest = *src;` copies one letter. Then move both along with `dest++` and `src++`.
Stop at `src`'s `'\0'`, and remember to put a `'\0'` on the end of `dest`!

[lesson]
copy_string with pointers:

    while (*src != '\0') {
        *dest = *src;
        dest++;
        src++;
    }
    *dest = '\0';

Both pointers walk along together.
The '\0' at the end is NOT optional.

Exam 2: copy_string.

[hint]
Copy one letter with *dest = *src; then move both pointers along.
Loop while *src != '\0'. After the loop, put a '\0' on the end of dest.
while (*src != '\0') { *dest = *src; dest++; src++; } then *dest = '\0';

[solution]
void copy_string(char *dest, char *src) {
    while (*src != '\0') {
        *dest = *src;
        dest++;
        src++;
    }
    *dest = '\0';
}

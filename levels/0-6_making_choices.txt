title: B.6  Making Choices
type: escape
buttons: NORTH | SOUTH | == | read()

[story]
Bitty: "Two ways to go. The number on the floor tells me which one is safe."
Goal: use if / else to choose the safe path.

[talk]
@walk EAST 1
Real programs make choices. On the data tile, `read()` tells me its number.
`if (read() == 5) { ... } else { ... }`: if the number is 5, do the first part. Otherwise, do the part after `else`.
Two `==` ASKS "are these the same?". One `=` puts a value in a box!

[lesson]
if lets your code make a choice.

    if (read() == 5) {
        move(NORTH);    // only if true
    } else {
        move(SOUTH);    // only if false
    }

The ( ) holds a QUESTION. The answer is
always true or false.

    ==   is equal to
    !=   is not equal to
    >    is bigger than
    <    is smaller than

Watch out:
    x = 5      PUT 5 in x
    x == 5     ASK if x is 5

[hint]
Step onto the data tile first. read() tells you its number.
Use if (read() == 5) to go NORTH, and else to go SOUTH.
After move(EAST); write: if (read() == 5) { move(NORTH); } else { move(SOUTH); }

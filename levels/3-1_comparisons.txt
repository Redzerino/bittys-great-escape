title: 3.1  Comparisons
type: repair
buttons: a > b | a < b | a == b

[story]
Bitty: "The control unit keeps asking me which number is bigger. Every. Single. Time."
Write biggest() to return the larger of two numbers.

[talk]
@walk EAST 1
The CPU Control Unit makes decisions. `a > b` asks "is a bigger than b?" The answer is true or false.
Inside an `if`, `return a;` hands back a straight away, and nothing after it runs.
Give back the bigger number. Careful: -1 is bigger than -4!

[lesson]
Comparisons give true or false:

    a > b     bigger than
    a < b     smaller than
    a >= b    bigger or equal
    a <= b    smaller or equal
    a == b    equal
    a != b    not equal

Use them to choose what to return:

    if (a > b) {
        return a;
    }
    return b;

If the if returns, the code after it
never runs.

[hint]
Use an if to ask which number is bigger.
If a > b, return a. Otherwise return b.
if (a > b) return a; otherwise return b;

[code]
// STAGE 3.1: COMPARISONS
// Return the bigger of a and b.
// biggest(3, 7) -> 7
// Fill in the gold gaps!

int biggest(int a, int b) {
    if (___) {
        return a;
    }
    return b;
}

[solution]
int biggest(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}

[tests]
biggest(3, 7) == 7
biggest(9, 2) == 9
biggest(-4, -1) == -1
biggest(5, 5) == 5

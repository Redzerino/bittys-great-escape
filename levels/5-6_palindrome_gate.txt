A palindrome reads the same forwards and backwards: 121, 1221, 7.
You already built `Reversed()` in the Digit Peeler. It's written for you below.
So a number is a palindrome if reversing it gives the same number. One line!

[lesson]
A function can call another function.
That's what helpers are for.

    int Reversed(int n)        123 -> 321

A palindrome is the same when reversed:

    121  reversed is 121   -> palindrome
    123  reversed is 321   -> not one

    return Reversed(n) == n;

== already gives true or false, so you can
return it straight away.

[solution]
int Reversed(int testNumber) {
    int result = 0;
    while (testNumber > 0) {
        result = result * 10 + testNumber % 10;
        testNumber = testNumber / 10;
    }
    return result;
}

bool isAPalindrome(int testNumber) {
    return Reversed(testNumber) == testNumber;
}

title: 7.1  Character Codes
type: repair

[story]
Bitty: "The Data Bus SHOUTS everything. Let's turn small letters into capitals."
Write toUpper() to turn a lowercase letter into a capital.

[talk]
@walk EAST 1
Secret: a `char` is really a number. 'A' is 65, 'a' is 97. So you can do maths with letters!
A small letter is 32 more than its capital. `c - 'a' + 'A'` turns 'b' into 'B'.
Only change small letters: check `c >= 'a' && c <= 'z'` first.

[lesson]
A char is stored as a number (ASCII):

    'A' = 65    'a' = 97
    'B' = 66    'b' = 98
    'Z' = 90    'z' = 122

small letter - 32 = capital letter

    if (c >= 'a' && c <= 'z') {
        return c - 'a' + 'A';
    }
    return c;

&& means AND: both must be true.
|| means OR: at least one is true.

[hint]
Only small letters change. Check c is between 'a' and 'z'.
To turn a small letter into a capital, take away 32 (or do c - 'a' + 'A').
if (c >= 'a' && c <= 'z') return c - 32; otherwise return c;

// STAGE 7.1: CHARACTER CODES
// Turn a small letter into a capital.
// toUpper('a') -> 'A'
// Anything else stays the same:
// toUpper('Q') -> 'Q'   toUpper('7') -> '7'

    return c;
}

[solution]
char toUpper(char c) {
    if (c >= 'a' && c <= 'z') {
        return c - 'a' + 'A';
    }
    return c;
}

[tests]
toUpper('a') == 'A'
toUpper('z') == 'Z'
toUpper('m') == 'M'
toUpper('Q') == 'Q'
toUpper('7') == '7'

[story]
Bitty: "Gates! They don't open for walking. They open for answers."
Write doubleIt() so it gives back twice the number it is given.

[talk]
@walk EAST 1
Welcome to the Register Bank! These glowing gates don't open for walking. They open for ANSWERS. Now you write a `function`, and each gate tests it.
A function is a little machine: a number goes in (`n`), and `return` hands the answer back out.
This gate wants double the number. Fill the gold gap so it gives back `n * 2`. When you press RUN, I'll be beamed inside to act it out!

[lesson]
A function is a named piece of code that
takes values in and gives one back.

    int doubleIt(int n) {
        return n * 2;
    }

  int        the type it gives back
  doubleIt   its name
  (int n)    what it takes in: a whole
             number, called n inside
  return     hand the answer back

Calling it:   doubleIt(5)   gives 10

Each gate calls your function with a
different number and checks the answer.

[hint]
The gate gives you a number called n. What do you do to a number to double it?
Double means times 2. In C, times is the * sign.
return n * 2;

[code]
// STAGE 2.1: FIRST FUNCTION
// Make doubleIt() give back twice
// the number it is given.
// doubleIt(5) should give 10.
// Fill in the gold gaps!

int doubleIt(int n) {
    return n ___ 2;
}

[solution]
int doubleIt(int n) {
    return n * 2;
}

[tests]
doubleIt(2) == 4
doubleIt(5) == 10
doubleIt(0) == 0
doubleIt(21) == 42

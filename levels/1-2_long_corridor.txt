[story]
Bitty: "That's a LONG way. My battery won't last if you type every step."
Goal: reach the EXIT using a loop.

[talk]
@walk EAST 2
Look at the sign: the exit is 11 tiles away! Typing 11 moves would drain my battery.
A `for` loop repeats the code in its `{ }`. Put the number of times in the gold gap.
Watch `i` count up in the Inspector while I walk!

[lesson]
A for loop repeats code a set number of times.

    for (int i = 0; i < 3; i++) {
        move(EAST);
    }

It has three parts, split by ;
  int i = 0   start: make a counter
  i < 3       keep going while this is true
  i++         after each loop, add 1 to i

i goes 0, 1, 2 so the body runs 3 times.
Watch the Inspector: you'll see i count up.

[hint]
Don't type eleven moves! Use a for loop that runs 11 times.
for (int i = 0; i < 11; i++) runs the code inside the { } 11 times.
for (int i = 0; i < 11; i++) { move(EAST); }

[story]
Bitty: "Three or more of the same pixel in a line is a glitch. Find the first one, score it, and blank it out."
Write ReplaceWithMinusOne(): score the first line of 3+ identical items and replace it with -1's.

[talk]
@walk EAST 1
Scan the grid from the top-left, row by row. At each box, look RIGHT first: are there 3 or more the same in a row?
If not, look DOWN from that box. The first line you find is the cluster: add up its values, set its boxes to -1, and return the score.
Only values 1 to 4 count. 0 and -2 are never part of a cluster. No cluster anywhere? Return 0.

[solution]
int ReplaceWithMinusOne(int array[4][6]) {
    for (int row = 0; row < 4; row++) {
        for (int col = 0; col < 6; col++) {
            int v = array[row][col];
            if (v < 1 || v > 4) continue;

            int len = 1;
            while (col + len < 6 && array[row][col + len] == v) len++;
            if (len >= 3) {
                for (int k = 0; k < len; k++) array[row][col + k] = -1;
                return v * len;
            }

            len = 1;
            while (row + len < 4 && array[row + len][col] == v) len++;
            if (len >= 3) {
                for (int k = 0; k < len; k++) array[row + k][col] = -1;
                return v * len;
            }
        }
    }
    return 0;
}

title: 8.1  Memory Addresses
type: repair

[story]
Bitty: "I doubled the value... but only my copy. I need its address!"
Fix doubleValue() so it changes the real value through a pointer.

[talk]
@walk EAST 1
Every box has an `address`, like a house number. A `pointer` holds an address: `int *p`.
`*p` means "the box p points at". Follow the cable!
This code doubles a copy, which vanishes. Double `*p` itself: `*p = *p * 2;`

[lesson]
POINTERS hold addresses.

    int score = 5;
    int *p = &score;   // p = address of score

    *p          the value p points at (5)
    *p = 10;    changes score to 10!

    &x   "address of x"
    *p   "the value at address p"

Passing an address lets a function
change the caller's variable:

    doubleValue(&score);

[hint]
x is just a copy. Change the value that p points at instead.
*p means 'the value at that address'. Double *p itself.
*p = *p * 2;

[code]
// STAGE 8.1: MEMORY ADDRESSES
// Double the int that p points at.
// x = 5; doubleValue(&x);  -> x is 10
// This only changes a copy!

void doubleValue(int *p) {
    int x = *p;
    x = x * 2;
}

[solution]
void doubleValue(int *p) {
    *p = *p * 2;
}

[tests]
doubleValue(&5) then #1 == 10
doubleValue(&0) then #1 == 0
doubleValue(&-7) then #1 == -14

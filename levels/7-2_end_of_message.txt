title: 7.2  End of Message

[story]
Bitty: "Count the vowels in each message. And no, the exam sheet's answer isn't always right."
Write countVowels() to count the vowels in a string.

[talk]
@walk EAST 1
A `string` is just an array of chars, like "Hello". But how does C know where it ends?
Every string has a hidden extra char at the end: `'\0'`, the null character. It means "the message stops here".
So to visit every letter, loop until you reach `'\0'`: `for (int i = 0; s[i] != '\0'; i++)`.
For each letter, check if it's a vowel, small or capital. That's a lot of `||` "or"s!
Fun fact: the Exam 2 prep sheet says "OpenAI" has 3 vowels. It actually has 4. O, e, A and I. The gate knows!

[solution]
int countVowels(char s[]) {
    int count = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        char c = s[i];
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u' ||
            c == 'A' || c == 'E' || c == 'I' || c == 'O' || c == 'U') {
            count++;
        }
    }
    return count;
}

title: 2.5  Digit Peeler
type: repair

[story]
Bitty: "This door reads its code backwards. 123 has to become 321."
Write Reversed() so it returns the digits of a number in reverse.

[talk]
@walk EAST 1
This gate reads numbers backwards: it wants 123 turned into 321.
Same tools as the Access Code: `% 10` takes the last digit, `/ 10` chops it off.
The new trick: `result * 10 + digit` sticks the digit on the end. 3, then 32, then 321!

[lesson]
Two operators peel digits off a number:

  %  remainder:  123 % 10  is  3  (last digit)
  /  divide:     123 / 10  is  12 (drop it)

int / int throws the decimal away.
That's exactly what we want here!

Build the answer one digit at a time:
    result = result * 10 + digit;

Exam 1, Q2 (helper for the palindrome).

[hint]
It's like the Access Code: loop while number > 0 and use the last digit each time.
Instead of adding the digit to a total, stick it on the end of result: result = result * 10 + digit.
Loop while number > 0. Each time: result = result * 10 + number % 10; then number = number / 10;

[code]

[solution]
int Reversed(int number) {
    int result = 0;
    while (number > 0) {
        result = result * 10 + number % 10;
        number /= 10;
    }
    return result;
}

[tests]

Reversed(1) == 1
Reversed(1200) == 21

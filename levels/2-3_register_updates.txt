title: 2.3  Register Updates
type: repair
buttons: a | b | c | / | *

[story]
Bitty: "Three sensors, one average. Careful, these registers only hold whole numbers."
Write average() to return the average of three numbers.

[talk]
@walk EAST 1
This function takes in THREE numbers: `a`, `b` and `c`. The gate fills in all three.
`total += a;` means "add a to total". It's short for `total = total + a;`.
Add all three, then divide by 3. Whole numbers drop any remainder, so 5 / 3 is just 1.

[lesson]
Shortcuts for changing a variable:

    total += 5;    total = total + 5;
    total -= 5;    total = total - 5;
    total *= 2;    total = total * 2;
    count++;       count = count + 1;

INTEGER DIVISION drops the remainder:

    10 / 3   is 3
    5 / 3    is 1
    2 / 3    is 0

Average of a, b and c:

    (a + b + c) / 3

[hint]
Add a, b and c together, then divide the total by 3.
The code already has total += a; Add the same line for b and for c.
total += b; total += c; then return total / 3;

[code]

// Fill in the gold gaps!

int average(int a, int b, int c) {
    int total = 0;
    total += a;
    total += ___;

[solution]
int average(int a, int b, int c) {
    int total = 0;
    total += a;
    total += b;
    total += c;
    return total / 3;
}

[tests]
average(3, 4, 5) == 4
average(10, 10, 10) == 10
average(1, 2, 2) == 1
average(0, 0, 1) == 0
average(90, 80, 70) == 80

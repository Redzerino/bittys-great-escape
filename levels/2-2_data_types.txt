[story]
Bitty: "The registers sort everything by type. Numbers, letters, true or false."
Write isEven() so it says whether a number is even.

[talk]
@walk EAST 1
Every box has a `type`: `int` is a whole number, `char` is a letter, `bool` is true or false.
This function gives back a `bool`: true if `n` is even. `n % 2` is the remainder after dividing by 2, and for even numbers it's 0.
A comparison like `n % 2 == 0` is already true or false, so you can return it straight away!

[lesson]
Every variable has a TYPE:

    int  count = 42;      whole number
    char grade = 'A';     one character
    bool ready = true;    true or false

A comparison gives back a bool:

    7 > 3       true
    4 == 5      false

% is the REMAINDER after dividing:

    7 % 2   is 1     (7 = 3*2 + 1)
    8 % 2   is 0     (8 = 4*2 + 0)

So a number is even when n % 2 == 0.

[hint]
A number is even when 2 goes into it with nothing left over.
n % 2 is what's left over. For an even number that's 0, so compare it with == 0.
return n % 2 == 0;

[code]
// STAGE 2.2: DATA TYPES
// Return true if n is even,
// false if it's odd.
// isEven(4) -> true   isEven(7) -> false
// Fill in the gold gaps!

bool isEven(int n) {
    return n % 2 ___ 0;
}

[solution]
bool isEven(int n) {
    return n % 2 == 0;
}

[tests]
isEven(4) == true
isEven(7) == false
isEven(0) == true
isEven(-6) == true
isEven(13) == false

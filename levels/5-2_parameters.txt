title: 5.2  Parameters
type: repair

[story]
Bitty: "The volume knob goes from low to high. Anything outside that needs fixing."
Write clamp() with three parameters.

[talk]
@walk EAST 1
The values in a function's brackets are `parameters`. Each call fills them in: `clamp(15, 0, 10)` sets value 15, low 0, high 10.
Clamp keeps a number inside a range: too low gives back `low`, too high gives back `high`.
Otherwise the value is fine as it is.

[lesson]
PARAMETERS are the inputs to a function:

    int clamp(int value, int low, int high)

    clamp(15, 0, 10)
          |   |   |
      value  low  high

Inside the function they work just like
normal variables.

    if (value < low)  return low;
    if (value > high) return high;
    return value;

[hint]
There are three cases: too low, too high, or just right.
Check if (value < low) first, then if (value > high). Otherwise the value is fine.
if (value < low) return low; if (value > high) return high; return value;

[code]
// STAGE 5.2: PARAMETERS
// Keep value between low and high.
// clamp(5, 0, 10)  -> 5
// clamp(-3, 0, 10) -> 0
// clamp(15, 0, 10) -> 10

int clamp(int value, int low, int high) {
    return value;
}

[solution]
int clamp(int value, int low, int high) {
    if (value < low) {
        return low;
    }
    if (value > high) {
        return high;
    }
    return value;
}

[tests]
clamp(5, 0, 10) == 5
clamp(-3, 0, 10) == 0
clamp(15, 0, 10) == 10
clamp(7, 7, 9) == 7
clamp(100, 1, 99) == 99

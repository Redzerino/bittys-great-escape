title: B.5  Maths Machine
type: escape
door_code: 48

[story]
Bitty: "This door's code is a sum. I'm a robot, I should be good at this..."
Goal: work out the door code with maths in your code.

[talk]
@walk EAST 1
The sign says the code is 6 times 8. Let's make the computer do the maths!
In C: `+` add, `-` take away, `*` times, `/` divide. So `6 * 8` works out 48 for us.
The code adds instead of multiplying. Fix the sign!

[lesson]
C can do maths for you:

    +   add          5 + 2   is 7
    -   subtract     5 - 2   is 3
    *   multiply     5 * 2   is 10
    /   divide       10 / 2  is 5

    int code = 6 * 8;     code is 48

You can change a variable later:

    code = code + 1;      code is 49

The right side is worked out FIRST,
then the answer goes into the box on
the left.

Watch out: dividing whole numbers drops
the leftover. 7 / 2 is 3, not 3.5!

[hint]
The sign says 6 TIMES 8, but the code adds them.
In C, times is the * sign.
The door wants 6 times 8. In C, times is written *, so: int code = 6 * 8;

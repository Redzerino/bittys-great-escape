title: 4.4  Emergency Stop
type: repair

[story]
Bitty: "Find the smallest number that divides it. And stop the moment you find it!"
Write smallestDivisor() and use break to stop the loop early.

[talk]
@walk EAST 1
Find the smallest number bigger than 1 that divides `n` exactly. For 15 that's 3.
Try `d` = 2, 3, 4... When `n % d == 0`, you've found it.
`break;` jumps straight out of the loop, like an emergency stop.

[lesson]
break jumps out of a loop straight away:

    int d = 2;
    while (d < n) {
        if (n % d == 0) {
            break;      // found it, stop
        }
        d++;
    }
    return d;

After break, the code AFTER the loop
runs next.

continue is the opposite: it skips to
the next time round the loop.

[hint]
Try d = 2, then 3, then 4... When n % d == 0, you've found it.
Use break; to jump out of the loop as soon as n % d == 0. Then return d.
Loop d from 2; if (n % d == 0) break; then return d after the loop.

[solution]
int smallestDivisor(int n) {
    int d = 2;
    while (d < n) {
        if (n % d == 0) {
            break;
        }
        d++;
    }
    return d;
}

[tests]
smallestDivisor(15) == 3
smallestDivisor(49) == 7
smallestDivisor(2) == 2
smallestDivisor(97) == 97
smallestDivisor(100) == 2

[talk]
@walk EAST 1
The firewall wants to know which string comes first in the alphabet.
Walk both pointers along while the letters match and the string hasn't ended.
Then return `*a - *b`: negative if a comes first, positive if b does, 0 if they match.

[lesson]
compare_strings, like C's strcmp:

    0          a and b are the same
    negative   a comes first
    positive   b comes first

    while (*a != '\0' && *a == *b) {
        a++;
        b++;
    }
    return *a - *b;

Characters are numbers, so subtracting
them tells you which comes first.

[hint]

// STAGE 9.3: FINAL FIREWALL
// 0 if a and b are the same,

int compare_strings(char *a, char *b) {

[solution]
int compare_strings(char *a, char *b) {
    while (*a != '\0' && *a == *b) {
        a++;
        b++;
    }
    return *a - *b;
}

[tests]
compare_strings("apple", "apple") == 0
compare_strings("apple", "banana") < 0
compare_strings("cat", "car") > 0
compare_strings("abc", "abcd") < 0
compare_strings("", "") == 0

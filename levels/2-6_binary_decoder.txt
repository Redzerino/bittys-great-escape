[story]

Write convertBinarytoDecimal() without using the shift operator.

[talk]
@walk EAST 1
This machine talks in binary, just 1s and 0s. 110 means 6, because each place is worth double the one to its right: 1, 2, 4, 8...
Peel the digits off from the right with `% 10` and `/ 10`, like the last two gates.
When a digit is 1, add what its place is worth. Then double the place for the next digit.

[lesson]
In binary each place is worth double the
one to its right:

  place:   4  2  1
  digits:  1  1  0   =  4 + 2 + 0  =  6

The binary digits are stored as a normal
int here: 110 really is one hundred and ten.
So peel the digits off with % 10 and / 10,
and keep a "place" that doubles: 1, 2, 4, 8...

Exam 1, Q4.

[hint]
Peel the binary digits off from the right with % 10 and / 10, like the last two gates.
Keep a place value that starts at 1 and doubles each time. When the digit is 1, add the place value to result.
Start with result = 0 and place = 1. While the number is > 0: result += (number % 10) * place; place *= 2; number /= 10;

[solution]
int convertBinarytoDecimal(int binaryNumber) {
    int result = 0, place = 1;
    while (binaryNumber > 0) {
        result += (binaryNumber % 10) * place;
        place *= 2;
        binaryNumber /= 10;
    }
    return result;
}

[tests]
convertBinarytoDecimal(110) == 6
convertBinarytoDecimal(111) == 7
convertBinarytoDecimal(1) == 1
convertBinarytoDecimal(0) == 0
convertBinarytoDecimal(1010) == 10

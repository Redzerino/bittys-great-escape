[story]
Bitty: "Stairs! If there's a wall ahead I go down, otherwise I keep going."
Goal: use if / else inside a loop to get down the staircase.

[talk]
@walk EAST 1
A staircase! On every step I check the tile ahead with `scan(EAST)`.
Wall in front? Step SOUTH. Otherwise, step EAST. Put that `if` / `else` inside the loop.
Same few lines, a different choice each time. That's how real programs work!

[lesson]
An if inside a loop makes a new
decision every time round:

    for (int i = 0; i < 10; i++) {
        if (scan(EAST) == TILE_WALL) {
            move(SOUTH);
        } else {
            move(EAST);
        }
    }

scan(EAST) tells you what's in the next
tile: TILE_WALL, TILE_EMPTY, TILE_EXIT,
TILE_VOID, TILE_DATA...

[hint]
On every step Bitty has to choose: is there a wall ahead or not?
Inside the loop, use if (scan(EAST) == TILE_WALL) to go SOUTH, else go EAST.
Inside the loop: if (scan(EAST) == TILE_WALL) move(SOUTH); else move(EAST);

[solution]
for (int i = 0; i < 10; i++) {
    if (scan(EAST) == TILE_WALL) {
        move(SOUTH);
    } else {
        move(EAST);
    }
}

title: 7.4  Password Terminal
type: repair

[story]
Bitty: "The terminal wants the password. It has to match EXACTLY."
Write samePassword() to check if two strings are the same.

[talk]
@walk EAST 1
A password check! You might think `a == b` would compare two strings. It doesn't. For arrays it only compares where they live in memory.
To compare strings you have to check them letter by letter, from the start.
If you find two letters that are different, they don't match. Return false straight away.
If you reach the end of BOTH at the same time, every letter matched. Return true!
Watch out for "abc" and "abcd". They agree right up until one ends early. Capitals count too: "bitty" isn't "Bitty".

[lesson]
Never compare strings with == !
Compare them one char at a time:

    int i = 0;
    while (a[i] != '\0' && b[i] != '\0') {
        if (a[i] != b[i]) {
            return false;
        }
        i++;
    }
    return a[i] == b[i];

The last line: did they both end at the
same place? Only then is it a match.

[hint]
Loop while both have letters; if any a[i] != b[i] return false. At the end return a[i] == b[i];

[code]
// STAGE 7.4: PASSWORD TERMINAL
// true if a and b are exactly the
// same string, otherwise false.
// samePassword("bitty", "bitty") -> true
// samePassword("bitty", "Bitty") -> false

bool samePassword(char a[], char b[]) {
    return false;
}

[solution]
bool samePassword(char a[], char b[]) {
    int i = 0;
    while (a[i] != '\0' && b[i] != '\0') {
        if (a[i] != b[i]) {
            return false;
        }
        i++;
    }
    return a[i] == b[i];
}

[tests]
samePassword("bitty", "bitty") == true
samePassword("bitty", "Bitty") == false
samePassword("abc", "abcd") == false
samePassword("", "") == true
samePassword("open", "oven") == false

[talk]
@walk EAST 1
Let's build our own string length counter!
Start at 0 and move along until you find the `'\0'`. Where you stop IS the length.
The `'\0'` itself doesn't count, and an empty string is just a `'\0'`.

[lesson]
The length is how many chars come
BEFORE the '\0':

    "Hi"    'H' 'i' '\0'     length 2
    ""      '\0'             length 0

    int i = 0;
    while (s[i] != '\0') {
        i++;
    }
    return i;

Spaces count:   "a b"  is 3 long.

[solution]
int myStrlen(char s[]) {
    int i = 0;
    while (s[i] != '\0') {
        i++;
    }
    return i;
}

[tests]
myStrlen("Hello") == 5
myStrlen("") == 0
myStrlen("a b") == 3
myStrlen("Bitty's Great Escape") == 20

title: 7.3  String Length
type: repair

[story]
Bitty: "How long is a message? Count until you hit the hidden end."
Write myStrlen() to count the characters in a string.

[talk]
@walk EAST 1
C has a built-in `strlen` that tells you how long a string is. But how does it work? Let's build our own.
Start at position 0 and keep moving along until you find the `'\0'` at the end. The position you stop at IS the length.
The `'\0'` itself doesn't count. "Hi" has 2 letters, even though it uses 3 boxes in memory.
An empty string "" is just a `'\0'` on its own, so its length is 0.
Spaces and punctuation count as characters too!

[lesson]
The length is how many chars come
BEFORE the '\0':

    "Hi"    'H' 'i' '\0'     length 2
    ""      '\0'             length 0

    int i = 0;
    while (s[i] != '\0') {
        i++;
    }
    return i;

Spaces count:   "a b"  is 3 long.

Next: Measure the String does the same
with pointers instead of [ ].

[code]
// STAGE 7.3: STRING LENGTH
// How many chars are in s?
// (not counting the hidden '\0')
// myStrlen("Hello") -> 5

int myStrlen(char s[]) {
    return 0;
}

[solution]
int myStrlen(char s[]) {
    int i = 0;
    while (s[i] != '\0') {
        i++;
    }
    return i;
}

[tests]
myStrlen("Hello") == 5
myStrlen("") == 0
myStrlen("a b") == 3
myStrlen("Bitty's Great Escape") == 20

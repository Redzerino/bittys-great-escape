[story]
Bitty: "Careful! That glowing purple memory isn't allocated. If I step in, I'm gone."
You don't know how long the corridor is. Use scan() to check before you move.
Goal: go east until the wall, then south to the EXIT.

[talk]
@walk EAST 2
Careful! That purple glow is unallocated memory. If I step in, I vanish.
I don't know how far the wall is, so I can't count. A `while` loop keeps going for as long as its question is true.
`scan(EAST)` peeks at the next tile. Keep moving while it's NOT (`!=`) a wall, then go down to the exit.

[lesson]
A while loop repeats AS LONG AS its
condition is true. Use it when you don't
know how many times you'll need.

    while (scan(EAST) != TILE_WALL) {
        move(EAST);
    }

scan(EAST) looks at the next tile east.
!= means "is not equal to".

Watch out: == compares, = assigns.
while (x = 5) is a classic bug!

[hint]
You don't know how far it is, so use a while loop and scan() ahead.
Keep moving EAST while scan(EAST) != TILE_WALL. Then go down to the exit.
while (scan(EAST) != TILE_WALL) { move(EAST); } then move(SOUTH); twice.

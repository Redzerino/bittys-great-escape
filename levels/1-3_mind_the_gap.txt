[story]
Bitty: "Careful! That glowing purple memory isn't allocated. If I step in, I'm gone."
You don't know how long the corridor is. Use scan() to check before you move.
Goal: go east until the wall, then south to the EXIT.

[talk]
@walk EAST 2
Stop! See that purple glow below? That memory isn't allocated. If I step in, I vanish. Bzzt.
This time I don't know how long the corridor is, so we can't count the steps.
A `while` loop keeps going for as long as something is true.
`scan(EAST)` lets me peek at the next tile. So: while the next tile is not a wall, keep moving.
`!=` means "is not equal to". Careful: `==` compares two things, but `=` changes a value. Easy to mix up!

[lesson]
A while loop repeats AS LONG AS its
condition is true. Use it when you don't
know how many times you'll need.

    while (scan(EAST) != TILE_WALL) {
        move(EAST);
    }

scan(EAST) looks at the next tile east.
!= means "is not equal to".

Watch out: == compares, = assigns.
while (x = 5) is a classic bug!

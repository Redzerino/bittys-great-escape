[story]
Bitty: "A locked door! It wants a code. Good thing I can remember numbers."
Goal: store the door code in a variable, write it at the door, and walk through.

[talk]
@walk EAST 1
A locked door! The code is 7, and I need to remember it.
A `variable` is a box with a name. `int code = 7;` makes a box called `code` with 7 inside.
The box holds 0 at the moment. Change it to 7, then press RUN!

[lesson]
A VARIABLE is a named box that holds
a value.

    int code = 7;

  int       what kind of value: a whole
            number (an "integer")
  code      the name you give the box
  = 7       put 7 inside it

Using the name gives you the value:

    write(code);     same as write(7);
    printf("%d\n", code);   prints 7

%d inside printf means "put a whole
number here". The number comes after
the comma.

write(number) stamps a number on the
floor. Next to a locked door, the
door checks if it's the right code.

[hint]
The door's code is 7. What's in the box called code at the moment?
The box starts with 0 in it. Put 7 there instead.
Change int code = 0; to int code = 7;

title: 3.3  Multiple Routes
type: repair

[story]
Bitty: "The grading chip is broken. It gives everyone an F!"
Write grade() so it gives the right letter for each score.

[talk]
@walk EAST 1
Letter grades: 70+ is 'A', 60+ 'B', 50+ 'C', 40+ 'D', anything lower 'F'.
Chain the choices: `if`, `else if`, `else if`... C stops at the first one that's true.
So check the HIGHEST grade first. A `char` goes in single quotes: 'A'.

[lesson]
else if gives more than two choices:

    if (score >= 70) {
        return 'A';
    } else if (score >= 60) {
        return 'B';
    } else {
        return 'F';
    }

C checks from the top and runs ONLY
the first one that is true.

A char is one character in SINGLE
quotes: 'A'   'b'   '7'
Double quotes are for strings: "Hi"

[hint]
Use if, then else if, else if... and check the BIGGEST grade first.
if (score >= 70) return 'A'; then else if (score >= 60) return 'B'; and so on down.
if (score >= 70) return 'A'; else if (score >= 60) return 'B'; ... else return 'F';

[solution]
char grade(int score) {
    if (score >= 70) {
        return 'A';
    } else if (score >= 60) {
        return 'B';
    } else if (score >= 50) {
        return 'C';
    } else if (score >= 40) {
        return 'D';
    } else {
        return 'F';
    }
}

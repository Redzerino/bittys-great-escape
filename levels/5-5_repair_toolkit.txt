title: 5.5  Repair Toolkit
type: repair

[story]
Bitty: "A function that calls itself? That's either genius or a disaster."
Fix factorial() so it stops calling itself.

[talk]
@walk EAST 1
A function can call itself. That's called `recursion`, and it's a neat way to solve problems that contain smaller copies of themselves.
5 factorial is 5 * 4 * 3 * 2 * 1. Or put another way: 5 * (4 factorial). The function does a bit of work, then asks itself for the rest.
But there's a bug. Press RUN and watch what happens. It never stops calling itself until the stack of calls runs out of room. Stack overflow!
Every recursive function needs a `base case`: a point where it stops and just returns an answer.
For factorial, when n is 0 or 1, just return 1.

[lesson]
RECURSION: a function calling itself.

    int factorial(int n) {
        if (n <= 1) {
            return 1;         // BASE CASE
        }
        return n * factorial(n - 1);
    }

factorial(3)
  = 3 * factorial(2)
  = 3 * 2 * factorial(1)
  = 3 * 2 * 1              = 6

Without a base case it never stops,
and you get a STACK OVERFLOW.

[hint]
Add if (n <= 1) return 1; at the top of the function.

[code]
// STAGE 5.5: REPAIR TOOLKIT
// factorial(5) -> 120  (5*4*3*2*1)
// factorial(0) -> 1
// Press RUN first and see what goes
// wrong. What's missing?

int factorial(int n) {
    return n * factorial(n - 1);
}

[solution]
int factorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

[tests]
factorial(0) == 1
factorial(1) == 1
factorial(5) == 120
factorial(7) == 5040
factorial(10) == 3628800

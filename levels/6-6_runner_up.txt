[talk]
@walk EAST 1
Like the Power Audit, but now I need the runner-up: the second biggest number.
Keep TWO boxes: `largest` and `second`. A new champion pushes the old one down into second.
If every number is the same, there's no runner-up, so return -1.

[lesson]
Track the top two as you walk the array:

    int largest = -1, second = -1;

    if (arr[i] > largest) {
        second = largest;     // old champ drops
        largest = arr[i];     // new champ
    }
    else if (arr[i] < largest && arr[i] > second) {
        second = arr[i];      // new runner-up
    }

Starting at -1 works because every number
is positive. If second is still -1 at the
end, there was no runner-up.

Exam 1, Q9.

[hint]
Keep two variables, largest and second, both starting at -1, and look at every element.
A number bigger than largest pushes largest down into second. A number between second and largest becomes the new second.
if (arr[i] > largest) { second = largest; largest = arr[i]; } else if (arr[i] < largest && arr[i] > second) { second = arr[i]; }  then return second.

[solution]
int find2ndLargest(int size, int arr[]) {
    int largest = -1;
    int second = -1;
    for (int i = 0; i < size; i++) {
        if (arr[i] > largest) {
            second = largest;
            largest = arr[i];
        } else if (arr[i] < largest && arr[i] > second) {
            second = arr[i];
        }
    }
    return second;
}

[talk]
@walk EAST 1
This is it. The USB exit is right there. The door code is every number on the floor added together.
Walk EAST until the gate is in front of me, doing `total += read();` after each step.
Then `write(total);` at the door, and two more steps to FREEDOM. Let's go home!

[lesson]
Everything together:

    int total = 0;
    while (scan(EAST) != TILE_GATE) {
        move(EAST);
        total += read();
    }
    write(total);
    move(EAST);
    move(EAST);

  a variable    to remember the total
  a loop        to walk the corridor
  scan()        to know when to stop
  read()        the number on the floor
  write()       the code for the door

[hint]
Add up the floor numbers as you walk.
After each move(EAST); do total += read(); then write(total); at the door.
int total = 0; while (scan(EAST) != TILE_GATE) { move(EAST); total += read(); } write(total); then two moves east.

title: B.1  What Is Code?
type: escape
buttons: move(EAST);

[story]
Bitty: "Never written code before? Perfect. Neither had I, until about five minutes ago."
Goal: add instructions until Bitty reaches the EXIT.

[talk]
Hi! I'm Bitty. I can't think for myself: I only do exactly what your `code` tells me.
`move(EAST);` means "take one step east" (to the right). The exit is 3 steps away.
Tap the `move(EAST);` button until there are 3 of them, then press RUN!

[lesson]
CODE is a list of instructions.
The computer does them one at a time,
from the top line to the bottom line.

    move(EAST);
    move(EAST);
    move(EAST);

This program has 3 instructions.
Each one moves Bitty one step east.

The four directions:
    NORTH   up
    SOUTH   down
    EAST    right
    WEST    left

Every instruction ends with a ;
(a semicolon). It's like a full stop:
it tells C the instruction is finished.

[hint]
The exit is 3 steps to the right. Each move(EAST); is one step.
Copy the move(EAST); line so there are 3 of them, one under the other.
You need three lines that each say move(EAST);

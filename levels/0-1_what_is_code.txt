[story]

Goal: add instructions until Bitty reaches the EXIT.

[talk]
Hi! I'm Bitty. Before we escape, let's start right at the very beginning. No experience needed. Promise.
A computer is super fast, but it can't think for itself. It only does exactly what it's told. Nothing more, nothing less.
`Code` is just a list of instructions for a computer, written in a language it understands. The language here is called `C`.
Each instruction goes on its own line. `move(EAST);` means "Bitty, take one step east". East is to the right.
The panel on the left is where you type. When you're ready, press RUN (or F5) and I'll follow your instructions from top to bottom.
The exit is 3 steps away, but there's only 1 step written so far. Copy that line until there are 3 of them. Then press RUN!

[lesson]
CODE is a list of instructions.
The computer does them one at a time,
from the top line to the bottom line.

    move(EAST);
    move(EAST);
    move(EAST);

This program has 3 instructions.
Each one moves Bitty one step east.

The four directions:
    NORTH   up
    SOUTH   down
    EAST    right
    WEST    left

Every instruction ends with a ;
(a semicolon). It's like a full stop:
it tells C the instruction is finished.

[hint]
You need three lines that each say move(EAST);

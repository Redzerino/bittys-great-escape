title: 2.4  Access Code
type: repair
buttons: n % 10 | n / 10 | n * 10

[story]
Bitty: "The access code is all the digits of the number added together."
Write sumDigits() to add up the digits of a number.

[talk]
@walk EAST 1
The access code is all the digits added up: 123 is 1 + 2 + 3 = 6.
`n % 10` is the last digit (123 % 10 is 3). `n / 10` chops it off (123 / 10 is 12).
Add the last digit to `total`, chop it off, and repeat while `n > 0`. Watch the digits drop off!

[lesson]
Peeling digits off a number:

    n % 10    the last digit
    n / 10    the number without it

    1234 % 10   is 4
    1234 / 10   is 123

Loop until there's nothing left:

    while (n > 0) {
        total += n % 10;
        n = n / 10;
    }

1234 -> total 4, 7, 9, 10

[hint]
Use a while (n > 0) loop. Each time round, deal with the LAST digit.
n % 10 is the last digit: add it to total. Then n = n / 10 chops it off.
Inside while (n > 0): total += n % 10; n = n / 10;

[solution]
int sumDigits(int n) {
    int total = 0;
    while (n > 0) {
        total += n % 10;
        n = n / 10;
    }
    return total;
}

[tests]

sumDigits(9) == 9
sumDigits(0) == 0

title: B.3  Talking Back
type: escape
buttons: move(EAST);

[story]
Bitty: "I can talk to you through the console. Let's say hello!"
Goal: print a message, then walk Bitty to the EXIT.

[talk]
@walk EAST 1
Code can talk too! `printf("Hello!");` shows a message in the console under me.
Words go inside "quotes". `\n` at the end starts a new line.
Change the message to anything you like, then get me to the exit: 4 steps east.

[lesson]
printf shows text in the console:

    printf("Hello!\n");

  printf    the command: print
  "..."     the text, inside quotes
  \n        start a new line afterwards
  ;         end of the instruction

You can print as many lines as you like:

    printf("Beep.\n");
    printf("Boop.\n");

Notes for humans start with //
The computer skips them completely:

    // this is a comment

[hint]
Keep the printf line. Now Bitty still needs to walk to the exit.
The exit is 4 steps EAST. Add one move(EAST); for each step.
Keep the printf line, then add move(EAST); until there are four of them.

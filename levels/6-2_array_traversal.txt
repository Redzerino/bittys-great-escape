A loop to visit every box, an if to

[hint]
Visit every box, but only count the ones bigger than limit.
Inside the loop: if (arr[i] > limit) add 1 to count.
Inside the loop: if (arr[i] > limit) count++;

[solution]
int countAbove(int arr[], int size, int limit) {
    int count = 0;
    for (int i = 0; i < size; i++) {
        if (arr[i] > limit) {
            count++;
        }
    }
    return count;
}

[tests]

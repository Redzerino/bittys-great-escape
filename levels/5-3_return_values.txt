title: 5.3  Return Values
type: repair

[story]
Bitty: "The weather module only speaks Fahrenheit. Let's translate."
Write toFahrenheit() and return the answer.

[talk]
@walk EAST 1
This function works out the answer... and then never gives it back!
`return` hands the answer back AND ends the function.
Do the multiply before the divide, or whole numbers lose the remainder too early.

[lesson]
return hands a value back to whoever
called the function, and ends it.

    int toFahrenheit(int c) {
        return c * 9 / 5 + 32;
    }

    int f = toFahrenheit(100);   // 212

C does * and / before + and -, from
left to right. With whole numbers, the
order of * and / changes the answer:

    37 * 9 / 5   is 66
    37 / 5 * 9   is 63

[hint]
The maths is already there, but the function never hands the answer back.
Use return to give the answer back instead of keeping it in f.
return c * 9 / 5 + 32;

[code]
// STAGE 5.3: RETURN VALUES
// Celsius -> Fahrenheit
//   F = C * 9 / 5 + 32
// toFahrenheit(100) -> 212

int toFahrenheit(int c) {
    int f = c * 9 / 5 + 32;
}

[solution]
int toFahrenheit(int c) {
    return c * 9 / 5 + 32;
}

[tests]
toFahrenheit(0) == 32
toFahrenheit(100) == 212
toFahrenheit(-40) == -40
toFahrenheit(37) == 98
toFahrenheit(20) == 68

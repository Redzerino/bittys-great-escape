title: 2.1  Data Types
type: repair

[story]
Bitty: "The registers sort everything by type. Numbers, letters, true or false."
Write isEven() so it says whether a number is even.

[talk]
@walk EAST 1
Welcome to the Register Bank. Every box in memory has a `type` that says what kind of value it can hold.
`int` holds whole numbers like 42. `char` holds a single letter like 'A'. `bool` holds just `true` or `false`.
This gate wants a function that returns a `bool`: true if a number is even, false if it's odd.
The trick is `%`, the remainder. `n % 2` is what's left over after dividing by 2. Even numbers leave nothing: 0.
So the whole answer can be one line: `return n % 2 == 0;` The comparison itself is already true or false!

[lesson]
Every variable has a TYPE:

    int  count = 42;      whole number
    char grade = 'A';     one character
    bool ready = true;    true or false

A comparison gives back a bool:

    7 > 3       true
    4 == 5      false

% is the REMAINDER after dividing:

    7 % 2   is 1     (7 = 3*2 + 1)
    8 % 2   is 0     (8 = 4*2 + 0)

So a number is even when n % 2 == 0.

[hint]
return n % 2 == 0;

[code]
// STAGE 2.1: DATA TYPES
// Return true if n is even,
// false if it's odd.
// isEven(4) -> true   isEven(7) -> false

bool isEven(int n) {
    return false;
}

[solution]
bool isEven(int n) {
    return n % 2 == 0;
}

[tests]
isEven(4) == true
isEven(7) == false
isEven(0) == true
isEven(-6) == true
isEven(13) == false

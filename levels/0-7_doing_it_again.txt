title: B.7  Doing It Again
type: escape

[story]
Bitty: "Nine steps. Nine whole lines. There has to be a better way."
Goal: use a loop instead of writing every step.

[talk]
@walk EAST 1
The exit is 9 steps away. Typing 9 moves is boring. A `loop` repeats code for us!
`for (int i = 0; i < 9; i++)` runs the code in the `{ }` 9 times, counting with `i`.
The loop only counts to 3 at the moment. Change it to 9!

[lesson]
A LOOP repeats code for you.

    for (int i = 0; i < 9; i++) {
        move(EAST);
    }

Read it as: "for i from 0, while i is
less than 9, adding 1 each time: move"

  int i = 0   start counting at 0
  i < 9       keep going while true
  i++         add 1 to i after each go

i goes 0,1,2,3,4,5,6,7,8: that's 9 runs.

The code inside { } is the BODY of the
loop. It can be as long as you like.

[hint]
The loop runs while i < 3. How many steps does Bitty need?
Change the 3 so the loop runs 9 times.
Change i < 3 to i < 9.

// BOOTCAMP 7: DOING IT AGAIN

for (int i = 0; i < 3; i++) {

[solution]
for (int i = 0; i < 9; i++) {
    move(EAST);
}

Bitty: "This wire carries a message. I need to know how long it is."
Write strlen_ptr() with pointer arithmetic only.

[talk]
@walk EAST 1
How long is this message? No `[ ]` allowed.
Point `p` at the first letter, and slide it along with `p++` while `*p` isn't `'\0'`.
At the end, `p - str` is how many boxes apart they are. That's the length!

[lesson]
A string is a char array ending in '\0'.
There's no stored length: you count until
you hit the '\0'.

A pointer can walk along an array:
    char *p = str;
    p++;          now points at the next char
    *p            the char it points at

Subtracting two pointers gives how many
elements apart they are:   p - str

Exam 2, Q5.

[hint]
Slide a pointer along until it reaches the '\0'.
char *p = str; while (*p != '\0') p++; then give back how far it moved: p - str.
char *p = str; while (*p != '\0') p++; return p - str;

[code]
// STAGE 8.5: MEASURE THE STRING
// "Hello" -> 5
// No [ ] allowed: walk a pointer.

int strlen_ptr(char *str) {

    return 0;
}

[solution]
int strlen_ptr(char *str) {
    char *p = str;
    while (*p != '\0') p++;
    return p - str;
}

[tests]
strlen_ptr("Hello") == 5
strlen_ptr("") == 0
strlen_ptr("Bitty escapes!") == 14
strlen_ptr("a") == 1

[story]
Bitty: "No square brackets allowed. I'll have to walk along the array myself."
Write sum_array() using only a pointer.

[talk]
@walk EAST 1
In the Address Network, `[ ]` is banned (just like Exam 2). Use pointers!
`*arr` is the box the pointer is on. `arr++` slides it to the next box.
Do that `size` times and add them up. Watch the `arr` cable slide along!

[lesson]
Walking an array with a pointer:

    int total = 0;
    for (int i = 0; i < size; i++) {
        total += *arr;    // value here
        arr++;            // slide along
    }

    arr        address of the first box
    *arr       the first value
    *(arr + 2) the third value
    arr++      point at the next box

In Exam 2, [ ] is not allowed.
Exam 2: sum_array.

[hint]
*arr is the box the pointer is on. arr++ moves it to the next box.
Loop size times: add *arr to total, then do arr++.
total += *arr; arr++; inside a loop that runs size times.

[solution]
int sum_array(int *arr, int size) {
    int total = 0;
    for (int i = 0; i < size; i++) {
        total += *arr;
        arr++;
    }
    return total;
}

[tests]
sum_array({1, 2, 3, 4}, 4) == 10
sum_array({7}, 1) == 7
sum_array({-1, -2, 10}, 3) == 7
sum_array({20, 30, 50}, 3) == 100

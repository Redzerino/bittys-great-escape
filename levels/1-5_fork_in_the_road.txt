[story]
Bitty: "Two paths. One is the exit. The other is unallocated memory. No pressure."
The number on the data tile decides: bigger than 5 means NORTH, otherwise SOUTH.
Goal: use if / else to pick the right path.

[talk]
@walk EAST 2
A fork in the road. One way is the exit, the other is the void. Read the sign!
`if (read() > 5) { ... } else { ... }` goes the first way when the number is bigger than 5, and the other way when it isn't.
`>` bigger than, `<` smaller than, `==` the same as. Choose wisely, please!

[lesson]
if runs code only when a condition is true.
else runs when it is false.

    if (read() > 5) {
        move(NORTH);
    } else {
        move(SOUTH);
    }

Comparing:
  >   bigger than      <   smaller than
  >=  bigger or equal  <=  smaller or equal
  ==  equal to         !=  not equal to

Watch out: = puts a value in a variable.
== asks "are these equal?".
if (x = 5) is a bug. You meant if (x == 5).
